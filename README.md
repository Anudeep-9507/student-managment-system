# Student Management System

## 📖 Overview
The **Student Management System** is a Java-based application designed to streamline the management of student information. This system provides functionalities for adding, updating, deleting, and viewing student records, ensuring efficient and organized management of data.

---

## ✨ Features

- **Add Students**: Easily add new student records with relevant details.
- **Update Records**: Modify existing student information as needed.
- **Delete Students**: Remove student records from the system.
- **View Records**: Display all student information in an organized format.
- **Responsive Design**: Includes CSS styling for a clean and user-friendly interface.

---

## 🛠️ Technology Stack

- **Backend**: Java (88.9%)
- **Frontend**: CSS (11.1%)
